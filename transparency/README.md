# transparency/

This is the supplementary documentation archive for the paper *The Journal of Prompt Engineered (Moral) Philosophy: Or, Why AI-Assisted Ethics Research Requires Process Transparency*.

The paper introduces a five-element documentation-adequacy framework (SP-1 through SP-5) and treats its own production as an instance of that framework. The materials in this folder are the resulting record.

## Where to start

→ **`Canonical_MD/`** is the entry point. See `Canonical_MD/README.md` for an orientation to how the materials are organized, how provenance is recorded, and how metadata should be read.

The five Structural Partitions live there:

| Folder | Role |
|---|---|
| `Canonical_MD/SP1_AIUsageDeclaration/` | Declaration of how AI was used (concise entry point) |
| `Canonical_MD/SP2_NavigationAndArchitecture/` | Index to SP-3, SP-4, SP-5; document-type ontology |
| `Canonical_MD/SP3_DocumentationAdequacy/` | Adequacy argument (the author's case that the record satisfies the paper's §6 criteria) |
| `Canonical_MD/SP4_ProcessDocumentation/` | Modification logs, epistemic traces, section guidance, pattern summaries, reference logs |
| `Canonical_MD/SP5_DevelopmentRecords/` | Prompt development logs, working notes, section drafts |

## Not part of the archive

- `TEMP/`, `tmpclaude-*-cwd/` — local scratch areas, gitignored, not present in the public repository.
- Source conversations (raw chat transcripts with each model) are retained by the author, indexed by session identifier, and available upon request. See the paper's closing **AI Usage and Documentation Archive** note for scope and limits.
