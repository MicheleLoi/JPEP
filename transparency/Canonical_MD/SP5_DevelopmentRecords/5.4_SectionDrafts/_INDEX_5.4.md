# 5.4 Section Drafts (Type 12)

## Purpose

This folder contains working drafts of paper sections produced from guidance files (Type 4). These are intermediate artifacts in the development process—they become historical records after integration into the main paper file.

## Artifact Type

**Type 12: Section Draft**
- Produced by drafting AI using Section Guidance (Type 4) as input
- Contains section prose ready for integration
- Metadata links to source guidance file
- Versioned (e.g., "v3" indicates Stage III revision)
- Preserved after integration (not deleted)

## Relationship to Other Artifacts

```
Type 4 (Section Guidance)
        │
        ▼
Type 12 (Section Draft)  ← THIS FOLDER
        │
        ▼
Paper file (integrated)
        │
        ▼
Type 3 (Modification Log)
```
